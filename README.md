# ☾ BIRTH SKY, TODAY · 오늘, 나의 날씨

태어난 순간의 하늘(출생차트)과 **오늘의 하늘(트랜짓)** 이 만나는 지점을 읽어, 오늘의 감정·관계·행동의 가능성을 현대적인 언어로 번역하는 모던 애스트롤로지 자기성찰 웹앱입니다.

> 미래를 단정하지 않습니다. 오늘을 조금 더 선명하게 바라보게 합니다.

## 핵심 개념

일반 별자리 운세가 태양 별자리 하나로 모두에게 같은 내용을 주는 것과 달리, 이 앱은 **나의 출생차트 × 오늘의 천체 위치 × 오늘 활성화된 삶의 영역** 을 결합해 개인화된 "오늘의 날씨"를 보여줍니다.

## 기능

- 🌌 **출생차트** — 생년월일·시각·출생지로 태양·달·수성~명왕성, 정확한 상승궁·천정(MC), 홀사인 하우스, 네이탈 애스펙트 계산
- ☁ **오늘의 날씨** — 오늘의 트랜짓이 출생차트와 맺는 애스펙트를 중요도 점수화하여 핵심 신호 1~3개 선정
  - 오늘의 한 문장 · 날씨 요약
  - **에너지 계기판** 5축(추진력·감정 민감도·관계 개방도·집중력·변화 압력) — 길흉 점수가 아닌 상태의 성격
  - 핵심 천체 신호 카드(의미·주의·활용·천체 근거)
  - 활성화된 삶의 영역(하우스) · 감정 날씨(달) · 장기 배경(외행성)
  - 오늘의 활용법 · 주의할 자동반응 · 성찰 질문 · 작은 의식
- 🔭 **이중 차트** — 안쪽 출생차트 + 바깥쪽 오늘의 트랜짓, 핵심 접점을 선으로 표시
- 🌠 실제 별자리 성좌 SVG(별 이름 라벨·반짝임), 밤하늘 배경 패럴랙스, 타로풍 금빛 카드
- ☀☾ **별의 조언** — 오늘의 태양·달이 나의 별자리(출생 시각 입력 시 출생 달)와 맺는 사인 애스펙트 기반 조언 (랜덤 아님)
- 📓 **오늘의 기록(저널)** — 기분(복수 선택)·성찰 답변을 이 기기에 비공개 저장(localStorage), 프로필도 저장돼 재방문 시 자동 복원
- 📤 **공유 카드** — 오늘의 한 문장·질문을 담은 이미지 저장/문장 복사(출생 정보 제외)
- 🛡 **안전 원칙** — 사건 단정·공포 유발·의료/법률/재정 예언 금지, 금지 표현 필터 + 안전 문장 대체
- ♿ **접근성** — 차트·계기판 대체 텍스트(role/aria), 입력 aria-label, reduced-motion 지원, 면책 안내

## 계산 · 해석 분리 (스펙 §8.3)

- **계산 엔진** — 천체 위치·애스펙트·하우스·중요도 등 정량 데이터만 산출. 동일 입력 → 동일 결과(재현성).
- **해석 엔진** — 계산 데이터를 규칙·템플릿으로 한국어 문장으로 번역. 천체 위치를 임의로 만들어내지 않음.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 을 엽니다. 데모: `Demo Sky · 1990-05-15 10:30 · 서울`.

## 기술 스택

- [Next.js 16](https://nextjs.org) (App Router) · React · TypeScript · Tailwind CSS
- 모든 천체 계산은 자체 구현(Schlyter 천체력)으로 **브라우저에서 동작하며 외부 API가 필요 없습니다.**

## 정확도 검증

천체력을 표준 이페메리스와 대조: J2000(2000-01-01 12:00 UT) 기준 태양·달·수성~명왕성 위치가 모두 실제값과 ±0.5° 이내 일치, 춘·하지 태양 0.0°. 예: 2026-07-28 데모 프로필에서 `Transit Pluto ☍ Natal Asc · Orb 0.7° · Applying`가 메인 신호로 정확히 산출됨.

## 제한사항 (스펙 §36-16, 정직하게 기록)

- **해석은 AI가 아닌 템플릿 엔진**입니다. 스펙의 "안전 검증 실패 시 템플릿 대체"를 기본값으로 채택 — 자체완결·재현성·안전성을 우선했습니다. (추후 Anthropic API 연동으로 확장 가능)
- **하우스는 홀사인(Whole Sign)** 방식입니다. Placidus 등 다른 시스템과 하우스 경계가 다를 수 있습니다.
- **표준시 기준이며 서머타임(DST)은 미반영**합니다. 여름 출생·해외 도시는 경계 근처에서 한 칸 어긋날 수 있습니다.
- **현재 위치는 출생 도시로 기본 설정**됩니다(별도 현재 위치 선택기는 후속 예정).
- **출생 시각 미상 모드**에서는 상승궁·하우스·트랜짓 대시보드를 제공하지 않고, 태양궁 중심의 기본 리딩만 표시합니다.
- 저장은 **브라우저 localStorage**(이 기기) 기준입니다. 계정 동기화는 후속 범위입니다.
- **시간대별(아침·오후·저녁) 날씨**, 정확한 애스펙트 도달 시각, Chiron·노드 등 선택 포인트는 후속 범위입니다.

## 성격

본 서비스는 천체 상징을 활용한 문화적·자기성찰 콘텐츠이며, 의학·법률·재정·심리 상담 또는 과학적 예측을 대체하지 않습니다.
