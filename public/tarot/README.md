# 타로 카드 이미지 넣는 곳

Next.js는 `public/` 안의 파일을 웹 루트에서 그대로 제공합니다.
예) `public/tarot/major/00.jpg` → 앱에서 `/tarot/major/00.jpg` 로 접근.

## 넣을 위치 & 파일명 (메이저 아르카나 22장)

`public/tarot/major/` 에 **배열 순서(인덱스)** 대로 **2자리 숫자**로 저장하세요.
(코드의 `lib/tarot.ts` 순서와 1:1 매핑됩니다.)

| 파일명 | 카드 | 파일명 | 카드 |
|---|---|---|---|
| `00` | 0 · 바보 | `11` | XI · 정의 |
| `01` | I · 마법사 | `12` | XII · 매달린 사람 |
| `02` | II · 여사제 | `13` | XIII · 죽음 |
| `03` | III · 여황제 | `14` | XIV · 절제 |
| `04` | IV · 황제 | `15` | XV · 악마 |
| `05` | V · 교황 | `16` | XVI · 탑 |
| `06` | VI · 연인 | `17` | XVII · 별 |
| `07` | VII · 전차 | `18` | XVIII · 달 |
| `08` | VIII · 힘 | `19` | XIX · 태양 |
| `09` | IX · 은둔자 | `20` | XX · 심판 |
| `10` | X · 운명의 수레바퀴 | `21` | XXI · 세계 |

## 파일 규격 권장

- 형식: `.png` / `.jpg` / `.webp` 지원 (코드가 png→jpg→webp 순으로 시도)
- 권장 크기: 세로 기준 900~1536px 정도 (카드 세로 비율 2:3)
- 파일명은 위 표의 2자리 숫자만 사용 (예: `00.png`)
- 현재 배포된 카드: `00.webp`~`21.webp` (22장, png→webp 최적화 완료)

## 마이너 아르카나까지 (선택, 총 78장)

나중에 확장한다면:

```
public/tarot/
  major/00.jpg ... 21.jpg
  minor/wands/01.jpg ... 14.jpg
  minor/cups/01.jpg ... 14.jpg
  minor/swords/01.jpg ... 14.jpg
  minor/pentacles/01.jpg ... 14.jpg
```

## 업로드 후

파일을 넣고 알려주시면, 이모지 대신 **이미지를 카드 앞면에 렌더링**하도록 연결하겠습니다.
(이미지가 없는 카드는 기존 이모지로 자동 대체하도록 처리할 수 있습니다.)
